# Estymator — strona internetowa ML/AI

Strona internetowa Studenckiego Koła Naukowego **Estymator** działającego przy Politechnice Wrocławskiej. Projekt zawiera stronę główną oraz dwie osobne podstrony: dla studentów i dla firm.

## Struktura projektu

```text
.
├── index.html
├── studenci.html
├── firmy.html
└── README.md
```

## Opis stron

### `index.html`

Strona główna koła. Zawiera najważniejsze informacje o Estymatorze, obszarach działalności, wydarzeniach, zespole oraz linki do podstron.

### `studenci.html`

Podstrona skierowana do studentów. Pokazuje, dlaczego warto dołączyć do koła, czego można się nauczyć i jak wygląda ścieżka rozwoju członka koła.

### `firmy.html`

Podstrona skierowana do firm i partnerów technologicznych. Przedstawia możliwości współpracy, potencjalne obszary projektowe oraz aktualnych partnerów, m.in. Nokia i Thaumatec.

## Technologie

Projekt został przygotowany jako statyczna strona internetowa.

Użyte technologie:

- HTML5
- CSS3
- JavaScript
- Google Fonts

Nie jest wymagany backend ani dodatkowe biblioteki instalowane przez npm.
